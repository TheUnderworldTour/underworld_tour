# Requirements

## Problem Statement
Many players who enjoy rhythm and roguelike games have limited opportunities to find both categories to apply to one title. We aim to create an experience that marries the 2 genres into a fun and streamlined software that will boast the replayability of roguelike games, and the punchy gameplay of rhythm games. The game features playing different instruments for the gameplay and to find a rhythm for each level to beat the bosses and get extra bonuses even after killing the boss of that level. With these bonuses the player can gain access to new items that positively affect the game for the player, new instruments, band skins, etc. 

## Functional Requirements
* FR-1 Game has a core rhythm game based loop
* FR-2 Game has roguelike elements, including but not limited to:
    * Variable map layouts
    * Items that effect score or gameplay
    * 
* FR-3 Game has mechanic to track and account for input/output latency
* FR-4 Player can save progress
* FR-5 Player can get bonuses after finishing the boss of levels 
* FR-6 Game doesn’t finish when the boss is killed 

## Non Functional Requirements
* NFR-1 Game should be downloadable in 1 packed file. The reason for this is to make it easy for the person downloading the game and not make the process difficult. 
* NFR-2 Game can only be played on a computer. Since we’re only coding this for key binds and to be on pc unfortunately will need to download this game on a computer.

## Constraints
* C-1 No online play
* C-2 Saving only occurs outside combat
* C-3 Limited songs/rhythms you can play in game
